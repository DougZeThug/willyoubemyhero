# Vendored: emilkowalski/skills

The UI/animation skills in this folder (animate, animate-expo, animation-performance,
animation-vocabulary, apple-design, ask-sonner, break-ui, choreograph,
emil-design-eng, find-animation-opportunities, gestures, improve-animations,
mobile-native, pick-ui-library, prototype, remove-animations, review-animations)
are copied verbatim from https://github.com/emilkowalski/skills
(commit 715c180), listed at https://aiforui.dev/skills.
MIT licensed, see EMIL-KOWALSKI-SKILLS-LICENSE. `write-swift` was left out: this is a web app.

Upstream installs with `npx skills@latest add emilkowalski/skills`; to update, re-copy
from the repo rather than editing here, so the diff stays an upstream diff.
