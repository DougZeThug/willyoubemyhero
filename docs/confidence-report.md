Written 2026-09-02 against commit `7d58470`, before the Phase 0 fixes in this
branch landed. The score, the tiers and the phased PR plan are the working
document for the next few weeks; update the score line when a tier closes.

## Context

The user asked for a 1–100 confidence score with reasons, a tiered plan showing
how much each change moves the score, and a phased PR plan for Lovable, Claude
Code and Codex. The first pass weighted the combine (one day a year) too heavily.
The main function of the app is the trading-card game: the daily pack, the daily
secret, editions, streaks, trophies, dust, the marketplace and trades. This
version re-audits that game specifically and re-scores. Everything below was
measured on HEAD `7d58470` in this container.

## Score: **62 / 100** (down from the 67 of the combine-weighted pass)

The suites are green and the engineering is unusually careful, but the card game
has more real loss and exploit paths than the combine did, and they sit on the
paths people take every day.

| **Daily card loop** — pack, secret, reveal, vault, streak, trophy | 30     | 19    | Pack state is persisted per step in IndexedDB; reveal, resume, midnight, reduced-motion and record-retry are all e2e-covered; editions and secret tiers are server-rolled.
